# Blinkit Sales Analysis | Power BI, SQL & Python

Analysis of 5000+ Blinkit orders to track sales, delivery performance & category trends.

## Key Insights
- **Total Sales:** 11.01M
- **Total Orders:** 5K
- **Avg Delivery Time:** 6.94 mins
- **On-Time Delivery:** 69.40%

## Tools Used
- Power BI - Dashboard & DAX
- Python - Data Cleaning
- SQL - Business Queries

## MY RECOMMENDATION
- 1. Increase dark stores in late-delivery areas to improve On-Time % from 69% to 85%.
- 2. Give offers on Fruits & Vegetables during peak hours to increase sales by 15-20%.
- 3. Track late orders daily to reduce customer complaints.
